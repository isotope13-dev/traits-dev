Trojan-Downloader.JS.Iframe.ot -- MALICIOUS
Identity: HTML family-photo cover page containing an obfuscated PHP IRC bot.
The server-side code requires PHP short tags. The collector's JS name does
not identify its operative language. PHP configuration says version 1.28d.
Base64 is followed by cyclic byte subtraction; the key index is (i % n)-1,
so the first character uses the last key byte. Both subtraction keys and all
command names/configuration values were reconstructed without running PHP.
The bot connects to one of eight shuffled servers on port 8080, registers
with IRC PASS/USER/NICK, answers PING, joins ##-u, authenticates operators by
MD5 and hostmask, and also accepts channel-topic commands. It can evaluate
PHP, execute shell commands with several fallback APIs, download arbitrary
URLs to operator-selected paths, read files back over IRC, modify ownership
and permissions, send mail, and probe ports. The photo page, hosting ads,
analytics and browser popup shim are cover or unrelated third-party content.
Examples of recovered endpoints: homelessman.weedns.com, ns10.suroot.com,
and mcarlos.opendns.be. No endpoint is required by a detection rule.
Detection: two hostile composites, precision 6.1 each. New neutral evidence
covers IRC tokens, socket assignment, PHP Base64 syntax, ordinal subtraction,
command-prefix slicing, and permission changes. Ordinary error suppression
is notable. The dollar-variable system matcher is language-neutral in name.

Trojan-Downloader.JS.Timul.da -- MALICIOUS
Identity: HTML rotating-alphabet JavaScript exploit router.
Two alphabets map each input character by index, with identity fallback.
After each document-write call, the source alphabet rotates one position.
The first decoded script inhibits selection/context menus and blanks status.
The second uses a daily cookie, an MSIE-7 exclusion, ActiveX probes, and
zero-height frames targeting 1.gif, 2.htm through 7.htm, and uu.htm.
Targets include GLIEDown.IEDown.1, Downloader.DLoader.1, Snapshot Viewer,
HanGamePluginCn18.HanGamePluginCn18.1, and IERPCtl.IERPCtl.1. RealPlayer's
PRODUCTVERSION comparison selects different payload pages. Those relative
payload pages are not supplied, so no particular vulnerability or downloaded
binary is asserted. Rizin confirms this is not a native executable; source
control flow and decoded document writes supply the useful analysis.
Detection: three suspicious observations. The algorithm-specific rotating
substitution rule was moved from syntax to encoding/custom; exact consumers
were updated. Static matching does not decode this arbitrary alphabet.
Only concealment can be supported by reusable YAML matching evidence; it
must not be inflated into an exploit conviction based on a packer alone.

Trojan-Downloader.JS.Small.dm -- MALICIOUS
Identity: HTML traffic hijacker and hidden DHTML pop-under launcher.
The outer percent-decoded script defines dF. It drops the input's final
character, percent-decodes the remainder, subtracts that final numeric key
from each character, then percent-decodes and document-writes the result.
Keys 2 and 3 reveal parent.window.opener.location manipulation and forced
navigation to traffdirect.info/in.cgi, plus a zero-size DHTML control with
CLSID 2D360201-FFF5-11d1-8D03-00A0C959BC0A. ActivateActiveXControls and
ActivateApplets are enabled. Its DOM.Script.setTimeout opens thetraff.com
and refocuses the cover window. There is no executable-download operation
in these bytes, and no native exploit is claimed.
Detection: two suspicious composites for concealed arithmetic document
reconstruction. Generic fromCharCode/unescape output is a notable DOM
capability, not an exploit chain. A generic Write(unescape(value)) matcher
was moved from filesystem writing to URL decoding, retaining its matcher
and scope; it does not establish the receiver is a file. Exact consumers
were updated. The decoder's full shifted payload is beyond the scanner's
current automatic decoding, so hostile findings would overstate YAML evidence.

Checks and placement review
Initial atomscan and cleave facts were collected for each original sample.
SHA-256 values were independently confirmed. Final atomscan used slow mode,
no update, no reference following, and CLEAVE_SKIP_CACHE=1.
The IRC command leaf describes encoded protocol tokens, not C2 intent; a
plain IRC client is a near miss for hostile composites. The command leaf has
one parent child, avoiding a sparse sibling partition. Existing socket
assignment evidence was reused with arbitrary PHP variable names.
Equivalent static/named PHP class-constant Base64 receiver spellings were
consolidated while preserving the separate self-specific consumer and union
consumer. This keeps the existing Base64 leaf at its 100-rule limit without
an artificial taxonomy split. The custom-decoder, socket-connect and direct-
eval leaves received no additional rules. Ordinal math is arithmetic and
percent decoding is URL decoding. Changed IDs' exact consumers were audited;
historical migration evidence was left as a historical record.
Positive and near-miss cases are in testdata/concealed-web-source/cases.json,
with check.py verifying criticality and absence of false filesystem writes.
Sources already establish malicious behavior, so external URLs were not
needed to resolve an otherwise benign-looking sample.
