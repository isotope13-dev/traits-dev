# Android APK mislabeled-bad review

Review in progress: the snapshot contains 40 packages, all initially labeled
bad. Labels and filenames are leads, not proof. Small-package scans from both
local scanners are in `/var/tmp/triage-android-{cleave,atom}-small.jsonl`;
medium-package scans use the corresponding `-medium.jsonl` files. DEX and
manifest inspection is static; no sample was executed.

- `2652bd208ccd07637d7be824570290e700d8d6eb39193c431948bcf17af4a19c` — **bad** — The app presents a justice-themed interface and registers an SMS receiver. Its legacy `android.telephony.gsm.SmsMessage` code reads received sender and message bodies, stores both in receiver fields, and launches a nested task that puts those fields in JSON and writes an HTTP POST body. Existing DEX rules missed the older SMS class and display-message accessor; those are now covered, and a separate rule combines the nested POST task and nearby SMS, JSON and HTTP call sites. Both scanners now report hostile evidence. Six size-preserving negative DEX mutations and full validation passed; Hopper confirmed the label.
- `b866b5fc9bfbea1f591f5f0e79be3f43d8ea2b119be940d6dc190a440072f1ef` — **bad** — The app registers a boot receiver and embeds a remote download-to-shell command with wget, BusyBox and Toybox fallbacks. The receiver attempts to start a process at boot. Static disassembly shows that its `Runtime.exec` argument array mistakenly places a URL in the executable position, so this packaged command does not launch as written; the manifest also lacks the Internet permission. A hostile finding combines the boot action, fallback downloader command and process call while describing them as clues, not successful execution. Both scanners report it; five negative DEX mutations and full validation passed. Hopper confirmed the label.
- `0d5fd1997ecb76a167df753d5cce7688dfd0d813c028c9644025da352af77b7d` — **bad** — Static review confirms ISO-DEP card communication and publication of card information to a channel carried over an external WebSocket. A local Portuguese screen asks for a four- or six-digit PIN during a card-verification flow. The restored hostile rule combines the card-relay evidence with the local card and PIN prompts; it does not claim that the entered PIN is transmitted. Both scanners match; modified APKs missing each of the PIN prompt, card prompt, channel or socket do not. Full validation passed and Hopper confirmed the label.
- `b6c42dd2f522b2424e77443472d6ad4a0710d738ef664d69a0141bb71b1424c3` — **bad** — Both ZIP headers mark the Android manifest and DEX as encrypted, but their stored data decodes directly to plaintext binary XML and DEX. The app also uses boot broadcasts, a heartbeat service and WorkManager to restart a separate target component. Both scanners retain hostile findings for this packaging obfuscation and persistence. The former launcher-hiding finding was removed: its component-setting call belongs to bundled scheduler code, and did not establish launcher suppression. Full validation passed and Hopper confirmed the label.
- `5d666a2b3ae54f8ccc7d5a604d8c57d34ef420e1d32fbe9880f676a11b2f6c11` — **bad** — The game-themed app's initialization passes `/data/`, `/sys/` and `/system/` to its recursive file-deletion helper. Android access controls can prevent these deletions; the finding correctly describes attempts rather than successful wiping. Both scanners report the data/system deletion attempt as hostile. The earlier static review and current bytecode agree, full validation passed, and Hopper confirmed the label.
- `987de962717a336eee8d5f5d8e7abcbd5c1cdadbadfccde2fadcd864e0774bb8` — **bad** — The bank-security-themed app implements NFCGate-style reader behavior: its tag wrapper invokes `transceive` reflectively and the app builds NFC data messages for a socket channel. Separately, its inbox task reads SMS sender, body and date, then passes them to a routine that constructs and sends an HTTP request. Its declared card-emulation service returns no response, so this review does not claim the emulation path works. Both scanners identify the NFC relay and SMS exfiltration; validation passed and Hopper confirmed the label.
