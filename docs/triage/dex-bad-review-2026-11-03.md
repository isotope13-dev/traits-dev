# DEX mislabeled-bad review — 2026-11-03

The 40 snapshot artifacts include raw DEX, APK, XAPK, ZIP, and one wheel with an embedded APK. Both scanners were run on the artifacts; archive members and code or strings were inspected before assigning labels. The resulting labels are 10 bad, 1 good, and 29 inconclusive.

`69faf878eb48` contains a Tasker automation package. Its SMS inbox URI and HTTP POST API triggered a hostile claim of SMS exfiltration, but these independent features do not establish that SMS data is sent. Moved the combination to `objectives/collection/messaging/sms::android-sms-inbox-and-http-post` and made it suspicious, with a description limited to the observed capabilities. Cleave rescanning removed the hostile root finding; Atom's overall model remains hostile despite this, so package authenticity and full behavior still need review.

The `android-emv-aid-{webview-bridge,touch-websocket,hidden-component}` combinations also show co-occurring APIs and payment application identifiers without establishing a proxy or dataflow. They are suspicious rather than hostile; the separately defined source rule requiring NFC transceive, WebSocket, and endpoint remains hostile. Several similarly structured Android app variants match these combinations and remain inconclusive pending further investigation.

The Python host-finding Telegram POST proof of concept `/var/tmp/triage-cargo-telegram-poc-control.py` still triggers hostile exfiltration traits after these changes. The change does not treat proof-of-concept status as benign.

`d476a5d4dc02` is an encrypted sample ZIP containing an APK with real manifest and DEX members alongside rooted manifest and DEX lookalikes, manifest-named parent paths, both slash conventions, and filler. Cleave can unpack it with its built-in sample passwords; manual extraction was used to inspect and construct a control. The new `objectives/anti-static/pack/archive::apk-rooted-conflicting-manifest-dex-decoys` combines those independent archive facts and flags both the original ZIP and extracted APK as hostile in Cleave; Atom also reports the hostile trait on the extracted APK, although its overall model probability is approximately 70%. Repacking without the rooted manifest and DEX lookalikes clears the new finding. This detects hostile obfuscation without claiming an unobserved payload function or adding engine features.

An unrelated overlong PostCSS dependency regex was split into bounded dependency-specific observations and a composite. Synthetic package manifests matched all three intended dependency names, and a different dependency did not. Concurrent taxonomy reorganization errors were repaired and full `make validate` passed after the fixes.
