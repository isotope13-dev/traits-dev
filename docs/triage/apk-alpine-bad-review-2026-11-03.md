# Alpine APK mislabeled-bad review

The snapshot contains 33 APK files, including three that
were pending when it was collected. Package names and prior labels are leads,
not evidence of behavior. Both current scanners were run on the 19 packages
at or below 200 KB; their reports are under `/var/tmp/triage-alpine-*-0.jsonl`.
The final uncached audit covers all 33 packages in both scanners, with reports
under `/var/tmp/triage-alpine-final-{cleave,atom}-{0,1}.jsonl`. It finds hostile
evidence in all 30 bad packages and one symlink warning in each of the three
reviewed good compatibility packages. The compiled signature databases in the
security-rule packages have no remaining suspicious or hostile findings.

The relevant shell code handles configuration, users, and service startup; it has no install hook or observed credential-exfiltration logic. Both scanners report one archive symlink-escape warning for intended absolute package links. The links can escape a manual extraction directory, but are package compatibility links rather than evidence of anti-analysis. Hopper moved it to good after validation.
