Four images contain multi-megabyte VBScript droppers which combine extensive colon padding with split encoded archives, decode and extract the archives, and run dropped executables. A new hostile composite combines the padding, reconstruction, decoding, archive extraction, and execution facts; both scanners match all four and clear a control without execution. `3442c434af4f` contains a VBScript that strips inserted markers to launch a hidden PowerShell download and execution chain. These three ISO images are not expanded into children by the current scanners, so their confirmed hostile findings apply to the extracted scripts rather than the outer images.

`97ef6f319bf8` uses an Edge-looking minimized shortcut to launch a bundled calculator beside a masquerading Windows codec DLL. A new disc-level composite combines the shortcut and DLL facts; both scanners detect the image and the finding clears on a rebuilt disc without the shortcut. `9dbff94d0f6f` contains a game-utility lure and an executable with WMI command-subscription, Run-key, and UserAssist-history references.
