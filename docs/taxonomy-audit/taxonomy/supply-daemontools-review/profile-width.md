# Profile directory width

The 150-child limit exposed a flat `metadata/file/profile` level with 151 immediate subdirectories. Six subject groupings now organize 24 existing leaves: shortcut, lexical, screen capture, agent, file operation, and memory. The level has 133 immediate children. The moved leaves retain their individual evidence boundaries and rule IDs apart from their directory prefixes; references in rules, review scripts, test data and the taxonomy guide were updated.
