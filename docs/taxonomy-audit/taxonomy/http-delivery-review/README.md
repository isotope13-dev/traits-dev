# HTTP delivery review

The legacy HTTP delivery directory is retired. Python fetch/evaluation,
installer acquisition, HTTP self-copy propagation, operator directory listings,
and NWHStealer identity now follow their supported behaviors or family. Generic
file-sharing APIs, Python function names and network/encoding co-occurrences
are evidence profiles rather than established droppers or C2 activity.

The cloud-storage rules require a storage URL and reversed PE-header text. Their
former JPEG-only alternative could not match a rule scoped to scripts or HTML
in the same file, and the original endpoint condition did not establish an
image URL. Family domain markers retain their PE and JavaScript coverage; their
minimum sizes equal the length of the required literal, so no possible match is
excluded merely because of file size.

The adjacent temporary-path directory was split into 52 directory/helper rules
and 33 temporary-artifact rules. Both former directory-wide consumers include
both leaves. Infection, process and network function-name references also moved
out of the crowded general naming directory by subject.
