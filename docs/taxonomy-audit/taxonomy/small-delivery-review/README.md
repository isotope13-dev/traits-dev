# Remaining small delivery branches

The remote descriptor and SCP chains move to their shell-evaluation and
file-execution subjects. The disguised executable mail attachment moves to
document masquerading; the WindowsApps rules move by process-launch mechanism.
The Android hidden-temp HTTP finding remains a probable acquisition clue, and
the Node SEA archive download/extract/launch combination is suspicious because
the same behavior can occur in an ordinary updater.

The Discord rule requires webhook POST, file-write and launch evidence but
does not establish a CDN download. The two former Zlob rules have no
family-specific evidence: Policies Run and process/network clues move to
persistence, while the unsigned embedded-PE and WinINet combination remains
a suspicious network profile. Direct consumers and the former dropper ancestor
were updated.
