# Shortcut overlay and builder review

The former overlay branch combined shortcut references with search, decoding and HTA markers. Search commands and individual format or encoding observations now have their own homes. The mshta and HTA combination remains an execution objective; the broader search and encoding combinations are suspicious evidence profiles because their conditions do not establish overlay extraction or execution.

The shortcut builder rules include generic function names, literals, and source-level construction clues. The JavaScript builder and Swift curl/temp-executable combinations are suspicious construction profiles: their conditions do not themselves establish a dropper or execution of the referenced file. Generic path literals no longer claim they are shortcut targets. A separate temp VBS path pattern and its string-reconstruction composite likewise describe partial evidence rather than a proven script drop and execution.

Existing references and the security-hosts correlation were migrated with the rules.
