# Telemetry and security string review

The retired telemetry leaf mixed analytics words, identity and system-field names, repeated tracking-related words, supporting composites and a logging symbol. These now live with analytics or source naming, system fields, token populations and a telemetry-identity profile. Their presence remains evidence of text and field names, not proof that data was collected or transmitted.

The retired security leaf contained scanner vocabulary, service/target version identifiers and YARA-X name or module-path references. These moved to security vocabulary, target naming and the YARA-X library respectively. A bare YARA-X string does not prove that the engine is linked; the descriptions now state the observed references. The YARA-X rules retain their matchers and scopes and have a one-byte minimum, implied by their nonempty text, to meet the existing well-known size policy. Consumers were updated.
