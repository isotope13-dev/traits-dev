# Download neighborhood review

Reviewed download rules now follow installer invocation, blockchain-backed
execution, network and PE evidence, Android command/path evidence, or the
ShellObject family markers. Packed sections, URLs, WinINet imports, or an
administrator check alone do not establish a downloader or payload launch.
Likewise, an IRC token with update/download words does not establish an
authenticated command surface. Descriptions and severities reflect those
limits while preserving the underlying conditions and content-based exclusions.

The former Nemucod timing rule checked a Date.now difference and fragmented
strings, not a timing threshold or a family identity. It and its consumers now
use an observation profile; fragmented ADODB and SaveToFile clues no longer
claim a download or execution. Two empty legacy placeholder files were removed.

Three exact ShellObject encoded strings are retained as family-specific,
whole-file observations. Cleave's section policy has a narrow exception tied to
each exact ID, severity and matcher, so the migration does not assume which PE
section contains them. Their size minima are entailed by the matched literals.
