# BSRC widget and Persistorito review

The BSRC widget family is classified with downloaders. The [MAL-2026-13690 advisory](https://osv.dev/vulnerability/MAL-2026-13690) describes installer beaconing and a conditional remote shell-script download; the existing family markers identify the related widget. One composite also matched ordinary widget context without a withdrawal record, so its name no longer asserts withdrawal.

Persistorito's own description explicitly advertises motivational messages and startup-folder and scheduled-task persistence. The matching product identity is therefore a notable VS Code extension, not a hostile supply-chain verdict. Generic VSIX and status-text observations moved to metadata. Two former composites depended on a synthetic missing-rule sentinel; they now describe the product-specific strings they actually match rather than claiming established persistence behavior. This classification does not claim that any unexamined version is safe.
