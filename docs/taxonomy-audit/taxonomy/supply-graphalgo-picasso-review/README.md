# Graphalgo and Picasso Image supply-chain review

The Netstruct indicators join the existing Graphalgo trojan family: the defining evidence is a trojanized graph library and its keyed loader, rather than the distribution route. Generic `initGraph` text, string joins, a `Scripts/startup.js` path, and a path plus hidden-spawn combination moved to neutral evidence profiles. The path and spawn alone do not establish Chrome persistence or a dropper.

The compromised Toptal Picasso Image package is classified with stealers because its family composite requires GitHub-token webhook exfiltration. Generic security-warning text and a version-number gap moved to package metadata, with neutral descriptions. The package-specific evidence remains with the family, and consumers were updated.
