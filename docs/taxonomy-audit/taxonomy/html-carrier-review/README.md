# HTML carrier and activation review

The legacy HTML delivery category grouped page construction, transformed text, remote script activation and product-specific observations under a dropper objective. The reviewed rules now follow the evidence they actually test:

- HTML and SVG blob, embedded-data and password-page clues are file profiles; construction alone does not establish payload delivery.
- Encoded script, constructor, reverse-string and remote-script creation clues are script transformation or network profiles when their conditions do not establish activation.
- Actual transformed evaluation, remote script activation, HTA download and execution, and the remote script-host launch are classified by their execution sink. The password-gated encrypted executable carrier is classified by its concealed payload container.
- The XLS-shaped URL path is a URL observation. ScreenConnect-specific tracking and download evidence belongs with the product.

ScreenConnect's existing product directory was also divided into installer and client evidence. References to the former parent continue to include both children; individual references were updated to the appropriate child.

The remaining drive-by blob rules in the legacy HTML directory require a separate review.

The remaining drive-by rules are now reviewed too. Download filename and MIME markers moved to browser download behavior. Base64-encoded ISO and ZIP reconstruction with browser download sinks moved to `objectives/anti-static/obfuscation/payload/browser-download`, reflecting likely concealed delivery. File navigation, unbound error-handler or encoded/obfuscated download clues moved to profiles without claiming a particular payload or remote execution. A computed click, a hex-named call and a Blob do not themselves establish a ZIP; an encrypted ZIP and Blob do not by themselves establish a download. The legacy HTML delivery directory is removed.
