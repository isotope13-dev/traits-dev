# Flash, remote search, and shortcut delivery review

Flash signatures are format observations; URLs and SWF filenames in a small compressed movie do not establish a remote load. The combined profile is notable rather than hostile.

The search-ms references distinguish remote UNC targets and redirects from invoice branding. A search URI with invoice language is suspicious evidence of a remote-share lure, rather than proof of malicious execution.

Shortcut-fetch syntax is a browser download capability, invoice text is document content, and the combinations that coax or deliver shortcuts for activation are execution lures. This retires the flash, search-connector, and shortcut legacy delivery leaves.
