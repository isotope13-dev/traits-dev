# Telnyx supply-chain review

The archive-member and encrypted-archive rules identify Telnyx source-package properties, not a compromise. They now live with the Telnyx Python library at notable severity, without an arbitrary archive-size ceiling.

The execution composites did not require a Telnyx-specific indicator. They now describe the inferred encoded-execution behavior rather than identifying a compromised Telnyx client. Their generic XOR comprehension, encoded function definition and Base64-like assignment clues have neutral homes; the XOR matcher does not itself identify WAV data. All rule references were updated.
