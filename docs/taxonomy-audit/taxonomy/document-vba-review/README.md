# VBA document delivery review

Office macro rules now follow their observed execution sink, WMI execution,
startup persistence, document obfuscation or supporting macro evidence. A
shell object or a generic Open call is not itself a file launch; the
corresponding HTTP-stream rule now describes those clues. Likewise, embedded
PE and COM references, an encrypted document with a second-stage name, and
fragmented URLMon and WScript references do not independently establish a
payload launch. Their rules remain suspicious evidence profiles.

The crowded script-host download directory was also reviewed with its siblings.
Browser-hosted COM launch chains now live under the browser-control command
sink. Self-decoding and hex-built launches move to their respective transformed
or embedded execution sinks; the Certutil stages and response evaluator move
by sink. This leaves 71 rules in the script-host download directory.
