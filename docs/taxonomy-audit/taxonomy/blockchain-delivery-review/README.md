# Blockchain delivery review

Transaction-derived source evaluation and browser-script stages follow their execution sink; IPFS file download and detached spawn chains follow file execution. The npm preinstall chain retains its supply-chain objective. Existing hidden-window launch findings were split out of the crowded fetch and runtime leaves before adding these rules.

An RPC hostname and module alias do not alone establish EtherHiding, and a Blockstream endpoint plus spawn and chmod does not establish OP_RETURN. An Ethereum address near file writing, chmod and detached spawn can support a payload-launch objective, but not a smart-contract claim. Generic response-evaluation and transaction wording are described as such.

XOR-encoded browser state, theme, crypto and localStorage strings remain observations. The Cloudflare-like domain is a decoded domain reference, not by itself proof of C2 or a software-family identity. The legacy blockchain delivery leaf is retired.
