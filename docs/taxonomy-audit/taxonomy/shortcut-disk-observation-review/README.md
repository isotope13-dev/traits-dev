# Shortcut file-on-disk observations

The individual observations formerly grouped as shortcut droppers now live with shortcut extensions, path and temporary-directory profiles, HTTP/batch references, content markers, and the command behaviors they indicate. Their former composite consumers were updated; the 26 composites remain in the legacy branch pending their own behavioral review.

Several names and descriptions were corrected: a relative path that merely looks random does not necessarily name a sibling EXE; copy and `.virus` suffixes do not prove a payload; text matches do not establish that a path is the shortcut target; and HTTP plus a batch-path reference does not prove a file was saved. The existing security-hosts correlation retains the moved evidence.
