# Utility-name review

The final legacy application-name file mixed references to named products, 7-Zip filenames and product labels, an Intel resource string, and repeated `_DI` tokens. Named references now sit with the relevant product or library; the generic WinRAR reference stays outside its product directory because that directory is used as a broad exclusion. Intel resource text and token counts have separate vendor and population subjects.

Name and filename references do not establish official provenance or impersonation. IDs and descriptions now say what was observed. The prior baseline 7-Zip label rollup is now a component: it is partial identity evidence and `well-known/` does not admit baseline traits. Existing consumers and suppressors retain their matching logic. Path-only basename facts retain their original size coverage; nonempty text markers have a one-byte minimum. Narrowly matched whole-file section exceptions preserve those text markers' original scope.
