# Browser and settings-name review

The legacy application-name leaf mixed browser names with other application evidence. Safari, Edge and Opera references now live with those products, while the ambiguous `Edge/` segment stays a browser-target reference and the bare Yandex word stays a vendor reference. The browser-list example is a text profile. Apple System Settings and System Preferences name references live with macOS system components. Name strings alone do not establish product execution or Apple Events.

The Internet Explorer name reference remains a separate tool-reference observation because the existing Internet Explorer directory is used in broad exclusions; adding a bare name there would widen those exclusions. The PE Edge name keeps its existing whole-file coverage through an ID-, severity- and matcher-specific section-filter exception. One-byte minimums on the moved well-known names are implied by their nonempty matchers. Original scopes and criticalities remain unchanged, and exact consumers follow their definitions.

Other application-name rules remain for separate review.
