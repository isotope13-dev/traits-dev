# Shortcut share and working-directory review

UNC paths in shortcut fields are path references. The presence of an executable path is not sufficient to establish its execution; the minimized command shortcut combining that reference with a shell is therefore a suspicious reference profile. Patterns that actually invoke a script host or chain remote launches live under shortcut process creation and remote-share execution. A relocatable IP-share target is suspicious path evidence; the matcher alone does not prove credential capture or malicious intent.

The former window-hiding branch did not test window state. Its working-directory observations are path references, and its shell-text combinations are suspicious profiles, not proof of staging or execution. The COM shortcut profile is also named for COM evidence generally: some included stream references are not inherently network-related.

References and the broad security-hosts correlation retain the moved rules.
