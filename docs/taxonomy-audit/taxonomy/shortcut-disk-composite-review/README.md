# Shortcut file-on-disk composite review

The remaining legacy composites now live with shortcut lure, masquerade, script-host, hidden or remote payload execution, and path or content profiles. The BITS plus batch-call chain remains an inferred fetch-and-launch objective, and the disguised document shortcut and system-name mimicry combinations retain their inferred objectives.

Combinations consisting only of generic relative paths, workdirs, window or file attributes, or text references are suspicious profiles or shortcut behaviors. In particular, random-looking text does not establish an EXE or a payload, and a PowerShell reference plus an HTA URL does not establish a download. The renamed rules describe their actual evidence, while references and the security-hosts correlation were updated.
