# Shortcut target review

The former shortcut dropper target branch combined individual interpreter arguments, icon references, hidden launches, WebDAV script hosts, download-and-execute chains, and partial network or path observations. The rules now live with those respective subjects, and consumers were updated.

A hidden interpreter or conhost proxy is suspicious by itself; it is not automatically a hostile dropper. URL, policy, window, icon and path combinations that do not identify a download or browser execution are suspicious profiles rather than asserted droppers. A shell32 icon is described as an icon reference, not independently as a lure. Stronger combinations retain their inferred remote script, WebDAV, concealed fetch, or masquerade objectives.

The broad security-hosts correlation retains the moved evidence.
