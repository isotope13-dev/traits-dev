# Legacy file-string review

The retired file-string leaf mixed document and credential suffix references, JVM log and filename constants, ordinary filenames, a Windows component name, a source member reference and a vocabulary word. They now live with their observed path, filename, file-read, vocabulary or product subjects. Names and suffixes alone still do not establish file access or collection.

The neighboring extension directory was crowded. Existing document references moved to the document path subject and mixed delimited extension-list observations moved to a filetype-list sibling; consumers were updated. The extension leaf now holds 76 rules by the inventory used for this review.

`desktop.ini` lives in a desktop-configuration sibling instead of broadening the system-configuration directory selector used by an IoT profile. The .NET component reference has a one-byte minimum, implied by its nonempty text matcher, and a narrowly scoped exception for its existing whole-file matching. The configs.h reference is split into disjoint source and binary components with a notable rollup to retain all original file types. Other matchers, scopes and criticalities are preserved.
