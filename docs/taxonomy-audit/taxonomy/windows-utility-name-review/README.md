# Windows utility name review

The retired Windows utility file mixed Microsoft Activation Scripts identity, a generic KMS title, Safe Mode and Defender option text, and an assignment fragment. The specific tool identity and its existing exception now live with the dual-use tool. The exception retains its original identity and title requirements; moving it does not add a new suppression condition.

The broader activation-tool-or-KMS name composite remains a neutral tool-reference component because its KMS alternative does not establish the specific tool's identity. Safe Mode and Defender titles, assignment text and their co-occurrence moved to wording, source syntax and a security-policy profile. Their names now describe the observed text rather than asserting the action occurred. Matchers, file-type scopes, criticalities and consumers are preserved.
