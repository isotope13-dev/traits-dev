# URL shortcut delivery review

Most `URL=` matchers lack an InternetShortcut header requirement: they describe URL assignments rather than proving a shortcut was opened or a file downloaded. The public-IP share reference still feeds the independent shortcut authentication-coercion rule. The NUL matcher establishes only a run of sixteen zero bytes in a large file, not that the whole file is padding.

Public-share shortcut targets, script-targeting shortcuts and document-name disguises are grouped by likely activation or masquerade. The ordinary WebDAV-script combinations remain suspicious because an accessible script target alone does not establish malicious execution. Disk-image PowerShell arithmetic and Rundll32 ordinal chains move to their supported obfuscation and execution subjects. The legacy URL-shortcut delivery directory is retired.
