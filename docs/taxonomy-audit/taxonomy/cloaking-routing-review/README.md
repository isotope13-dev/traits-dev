# Cloaking and delivery review

The crowded cloaking leaf was split by the supported effect: traffic routing,
redirects, and selectively delivered content. Existing rule IDs and consumers
were updated to the appropriate leaf. A selector for the parent still covers
the same descendants.

The legacy Adspect delivery composite describes controlled content routing,
including non-script actions, so it joins routing rather than claiming a
JavaScript execution sink. The referrer-gated Ajax evaluator does establish
remote response evaluation and moves to the corresponding payload sink.

The tiny-iframe and campaign-style gateway combination is suspicious routing
evidence. Its separate clauses do not establish that the URL is the iframe's
target or that an exploit was delivered. The old dropper ancestor consumer
retains exact alternatives for the three migrated findings.

The remaining referrer-gated injector was split by evidence and sink. Its
short indexed string assignments remain component fragments; the recovered
referrer/Ajax/eval marker combinations are partial obfuscation evidence. The
three response-evaluation findings move to in-process network evaluation,
and the remote script-element finding moves to the script-element sink. The
dropper ancestor consumer retains the four non-component findings explicitly.
