# Remaining download review

The legacy download directory is retired. Android installer APIs, installation
telemetry and opaque-asset co-occurrences are installation evidence; the
archive-wide scopes of the asset/session rules are unchanged. Cipher-class and
asset evidence does not by itself prove that the asset is decrypted into the
session. Device-admin and cleaner/API combinations likewise retain their
observations without claiming an unobserved installer trigger.

WSH/XMLHTTP with a nearby run and write remains a probable execution chain.
Generated names, a WScript reference and an executable URL without a run or
network call are supporting profiles. Generic temporary-file, cookie and
file-write fragments now follow their own subjects. The previous content-based
exclusions and benchmark downgrade remain in place.

The neighboring curl directory held 91 rules. It now has 57 command, 17 body,
and 17 library-binding rules. Existing recursive `curl/` references retain the
same alternatives, while exact references follow the relocated rules. Six WSH
rules that evaluated remote or decoded source were moved from file-execution to
their evaluation sinks, leaving the script-host download leaf at 66 rules.

Download-and-launch findings were reviewed by their activation target. The
former flat `spawn/fetch` rules now sit under
`file-exec/download/{native,runtime,script-host}`; archive-backed chains moved
to the existing `spawn/archive` category. Network acquisition remains part of
each chain, while these child categories make the launched target clearer.
Rule IDs stayed stable, and consumers now reference their new directories.
