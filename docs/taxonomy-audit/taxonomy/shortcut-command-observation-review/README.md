# Shortcut command observations

The former command-content branch combined individual syntax, option, extension, URL, COM, decoding and command observations with larger detection chains. Its 37 observations now live with those subjects; the 23 remaining composites retain updated references for their subsequent review.

Names and descriptions now distinguish references from behavior: a `Shell` text match is not a Konni-specific indicator, `schtasks` alone does not establish task creation, `-OutFile` does not establish downloading, and `SilentlyContinue` does not necessarily suppress progress. The MSHTML protocol reference does not by itself establish mshta execution, and the Base64 markers are prefixes rather than verified embedded files.
