# Fallback download review

The BITS-to-IEX cleanup chain and the hidden elevated executable launch are filed by execution sink. A list of fetcher names plus a shell script reference does not by itself prove a download-to-shell chain. A wget HTTP command near chmod may be ordinary installation, so it remains a notable download observation.

TLS version selection, a certificate callback reference and IWR text are TLS evidence without a required verification bypass. Multiple downloader references, a temporary EXE path or a dated archive URL likewise describe retrieval clues without proving fallback order, a plugin or payload execution. Mill-specific download variables live with the build tool. Its marker is no longer treated as independent evidence of hostile hosts-file modification.
