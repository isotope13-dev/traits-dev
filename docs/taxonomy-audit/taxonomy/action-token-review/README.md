# Action-token neighborhood review

The generic action-token leaf had 90 traits. Twenty-five were reviewed with
its siblings and moved by the subject their names actually describe: process,
network, security, cryptography, capture, host information, secrets and input.
These remain name observations; they do not establish that the named action
ran. The leaf now has 66 traits after receiving the remaining generic `Load`
symbol from the legacy environment staging rules. That symbol is a component,
not proof of an assembly load.

The two new action subjects, cryptography and security, contain four and three
traits respectively. Every affected directory is below the neighborhood-review
threshold. No directory limit changed.

[moves.json](moves.json) records original predicates, defaults and destinations.
Run `uv run docs/taxonomy-audit/taxonomy/action-token-review/check-moves.py`
to verify the moves and directory sizes.
