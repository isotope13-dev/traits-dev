# Managed network and reflection review

Seventeen composites moved from legacy managed staging by their likely
behavior or observed subject. Match conditions, scopes and confidence were
preserved; local and external references now follow the moved IDs. The remaining
legacy file contains bitmap and reflection combinations for a separate review.

HTTP, decoding and reflection combinations with probable in-memory loading
moved to `execution/payload/module-load`; the injection toolkit combination
moved to process injection. A cluster of method-name observations is a module
loading profile, not independent proof that the named operations ran. HTTP,
Base64 and reflection method enumeration is a suspicious interop profile. A
high-entropy section and reflection references do not establish decryption;
that combination is a suspicious module-loading profile. Descriptions name
the evidence and avoid asserting a binding between separate legs. Unsupported
inherited network or execution labels were removed where appropriate.
