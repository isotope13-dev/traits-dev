# Shortcut script-chain review

The shortcut script-chain rules now distinguish file writing and deletion, script-host invocation, shell launch, argument and path clues, and the combined hidden fetch and batch execution objectives. A temp script path does not itself show a dropped file; deleting a temp script does not establish self-deletion or when deletion occurs. The delayed-expansion matcher identifies variable assignments rather than proving that they build command names.

The data/document extension rollup is a shell-execution profile: its alternatives indicate paths passed to `cmd /c`, not necessarily an extension mismatch. Existing references and the security-hosts correlation were migrated with the rules.
