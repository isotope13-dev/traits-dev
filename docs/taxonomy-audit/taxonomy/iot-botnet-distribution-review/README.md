# IoT botnet distribution review

The 86-rule IoT botnet leaf was divided into fleet control, flood tasking,
and deployment or reinfection. The split preserves predicates and the existing
parent namespace while giving each leaf room to grow. Linfeng-specific markers
and composites moved to that recognized botnet's identity namespace; the
operator handle is component evidence and the family marker is notable.

The legacy SSDP/multi-architecture distributor finding now lives with IoT
propagation. Its description identifies the matched SSDP and distribution
clues without claiming a demonstrated transfer. The Condi consumer and the
former dropper-ancestor consumer were updated. There were no direct selectors
for the old IoT leaf.
