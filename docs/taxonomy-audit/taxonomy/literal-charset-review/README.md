# Literal and charset review

The legacy `metadata/file/literal` and `metadata/file/string/charset` leaves mixed alphabets, numeric-array measurements, hex text, DNS terminology, source fragments and other labels. They now live with their observed alphabet, array, hex, syntax, wording, identifier or text-shape subjects. A bracketed `256`, a setup phrase and split-related text in a string no longer claim an array declaration, lure or split operation.

The QWERTY alphabet matcher retains its original file-type scope and baseline criticality. Its destination is already covered by the validator's existing text-profile exception; no file-type limit or exception was changed. The other matching scopes and criticalities are preserved, and exact consumers were updated.
