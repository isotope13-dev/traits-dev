# Remaining document delivery review

The legacy document-delivery directory is retired. Network paths, encoded text,
URL schemes and archive member names now identify what is actually present;
Office embedded-file, RTF object, document-viewer and OLE-link combinations
remain evidence profiles where the conditions do not establish an action.
Generic words such as `freefood` are not domain or command-and-control evidence.
The PDF temporary-file write and process-launch combinations move to staging and
execution respectively, while the document-themed .NET combinations describe
observed loading or download/write clues. Filename-based test suppressions on
these observations were removed.

The neighboring 92-rule document-interpreter directory was divided into add-in,
command, macro, PDF and XML execution surfaces. Its StdOleLink and URL
combinations are profiles: finding a class and URL in one document does not
itself establish the linked target or its execution. Their consumers were
updated, and the overly broad exploit and payload descriptions were corrected.
