# Axios compromise and RAT review

The Axios compromise's distinctive cross-platform command protocol and campaign markers now live with a remote-access family rather than under its distribution route. Exact campaign-specific signatures no longer have arbitrary file-size thresholds.

Generic function names, encoded-array and arithmetic patterns, status text, registry names, process-list commands, temporary paths and timing clues moved to their subjects. The former three-of-seven family rollup could identify the RAT using only generic observations; it now requires the distinctive `rsp_peinject` protocol marker alongside two supporting clues. The fixed temporary path plus JSON/Base64 encoding is a suspicious profile, not a proven C2 agent. Consumers were updated.
