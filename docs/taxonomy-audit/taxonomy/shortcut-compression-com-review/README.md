# Shortcut compression and COM review

The former DeflateStream dropper branch matched references to decompression and Base64 plus a short marker or a PowerShell clue. Neither composite establishes a dropper or execution of decoded content, so these are now suspicious shortcut encoding profiles, with names and descriptions that state the observations. The `ZZZ` string is described as a marker rather than an inferred payload delimiter.

The former COM downloader composite required any two of five HTTP and stream references, including pairs that do not establish HTTP downloading. It is now a suspicious COM network/stream reference profile. Individual references are grouped by COM context. The separate HTTP response invocation pattern and its composite remain execution objectives under the response-body branch because the pattern explicitly invokes a response body.

References were updated and the existing broad security-hosts correlation retains the moved evidence, using directory references where it covers every rule.
