# Shortcut fetch-chain review

The former Remcos shortcut branch had no family-specific condition. Generic PowerShell type and operator references now live with source syntax, their co-occurrence is an operator profile, and the temp-script web request is a download behavior. The combined shortcut lure retains its behavioral evidence without claiming a malware family or asserting that the operators decrypt a domain.

The former HTTP command-and-control branch contained User-Agent references and a constructed-script network execution chain. These now live with User-Agent profiles and network script evaluation. A reference to a PowerShell User-Agent is not by itself evidence that it is fake.

The conhost/curl rules now distinguish shortcut target, path, string-count, background-launch and network indicators from the inferred payload-launch chains. The SystemRoot shell32 matcher is a path reference, not proof of icon placement, and the background TEMP matcher does not by itself establish an EXE extension. Existing references and the broad security-hosts correlation retain the moved rules.
