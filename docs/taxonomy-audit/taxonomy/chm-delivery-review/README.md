# HTML Help delivery review

Small HTML entry counts, OBJINST sections and Russian, Korean or Chinese locale IDs are document characteristics. Locale is not inherently foreign or hostile. A single topic with ordinary script primitives is a suspicious profile, not proof of a dropper. Base64 fragments of PARAM, OBJECT or Item1 are components, not standalone Shortcut evidence.

Shortcut activation, scheduled-task registration, registry Run writes, deserialization and packed executable evidence are filed by their supported behavior. WebClient download and PowerShell references do not establish that a downloaded file was launched. Obfuscated decoding and HTML reconstruction retain their concealment subject where their required evidence supports it.

The legacy CHM delivery directory is retired.
