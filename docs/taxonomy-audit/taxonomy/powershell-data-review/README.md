# PowerShell data staging review

Nine legacy rules moved by their evidence. Culture/EnglishName, HEAD and
ContentLength text moved to locale, request-method and content-length subjects;
the culture pattern alone does not establish a key. The binary-character and
PSHome-index combination moved to interpreter command execution: it indicates
an indexed invocation but does not identify its target as eval. Reordering,
Base64 and CBC clues moved to layered encoding, and image-pixel and crypto
combinations moved to image steganography. The rule requiring established LSB
extraction remains hostile; weaker co-occurrences are suspicious. Original
conditions, explicit scopes, confidence and exclusions are preserved, and
unsupported attack annotations were removed or narrowed.

A small synthetic data file intended as a positive test for the indexed-command
rule yielded no extracted text in cleave and did not match. A negative fixture
also did not match. These fixtures do not verify positive detection; the
original predicates were compared structurally against the moved rule.

Three crowded neighboring directories were split by mechanism:

- String concatenation: 90 to 76 direct rules; indexed-selection rules moved to
  `index-select` and split .NET reflection names to `broken-api`.
- Fragmentation: 87 to 68; generic network-fragment assignments moved to
  source literal metadata, with family-specific prefixes removed from their
  IDs, and question-interleaved strings moved to `interleave`.
- Reconstruction: 90 to 74; padded tokens moved to `interleave` and indexed
  reconstruction moved to `index-select`. Padded-token composites now describe
  the observed strings and are suspicious instead of asserting execution.

Fully qualified references were updated; no directory-wide references to the
source directories were found. The generic fragment assignment rules retain
an existing 128 KiB maximum, which may limit their consumers. New direct rule
counts are 20 for `interleave`, 54 for `index-select`, 31 for `broken-api`,
and 10 for source fragment assignments.
