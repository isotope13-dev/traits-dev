# ClickFix clipboard and ErrTraffic review

The remaining clipboard leaf mixed clipboard lures, execution, product URLs, encoded state strings and generic source fields. Its rules now follow those subjects:

- Clipboard delivery and terminal lures remain objectives; encoded browser loader evaluation is grouped by its constructed evaluation sink.
- Encoded state and mode strings are browser-session observations. Exact public Claude, ChatGPT and Copilot URLs live under their respective products; the cross-product observation stays a tool-reference profile.
- Interview field and redirect patterns are generic source/field observations; the combined page with camera and clipboard command remains an execution lure. A browser error message by itself is a wording observation.
- Context, operating-system and download parameters are URL query observations. The blockchain/clipboard combinations remain lures, and enabling SEE_MASK_NOZONECHECKS is grouped with quarantine bypass.
- Verification-comment/download and ServiceModelReg/injection-related combinations are supporting profiles: the alternatives do not all establish an ErrTraffic identity, actual injection, process hollowing, or a signed host.

The legacy ClickFix clipboard directory and its parent ClickFix delivery directory are retired. References, including family consumers, have been updated. Other legacy dropper delivery branches remain.
