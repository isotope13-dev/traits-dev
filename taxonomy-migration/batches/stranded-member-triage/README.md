The three archives retain their confirmed MALICIOUS labels. Individual byte analysis identified 19 BENIGN published Windows auditing tools/helpers and 10 MALICIOUS web backdoor payloads/templates. ## Evidence

Foofus fgdump orchestrates administrator-authorized IPC$ connections, temporary credential-audit services, helper upload, SAM/cached-domain/Protected Storage extraction, cleanup, and documented antivirus stop/restore. Its embedded CacheDump, pwdump6, pstgdump, servpw and lsremora executables/DLLs implement those documented roles. Rizin import/export and function analysis found GetHash exports, LSA/SAM routines, service dispatch, named-pipe output, LSASS lookup and helper injection. These are credential-audit capabilities, not evidence of an additional autonomous implant.

The ASPack-packed klogger was unpacked with CPU emulation and stubbed loader APIs. Its recovered main installs WH_KEYBOARD_LL, processes the message loop, translates key states and appends keystrokes to klogger.txt. The banner identifies Arne Vidstrom's klogger 1.0. No network transport or persistence was present in the recovered code.

QSD and CMD ASP expose request-driven shell execution and file control. Findsock searches existing socket descriptors with getpeername, duplicates the connected socket onto standard streams and launches an interactive shell. Pentestmonkey PHP reverse shells connect an outbound socket and relay process pipes. Laudanum PHP/ASP/JSP pages execute operator-supplied commands; hidden.php imports request variables and immediately invokes a request-controlled callable. Several distributed templates have placeholders or syntax defects; findings describe payload/template capabilities rather than claiming successful deployment.

## Trait corrections and verification

Moved Foofus identity into dual-use credentials, and Pentestmonkey identity into dual-use remote administration. Moved LSASS name/path references, security-vendor service-stop API clusters, and debug-privilege remote-memory APIs into neutral micro-behaviors. Updated all trait references. Credential extraction composites retain suspicious severity generally and notable severity only for strongly identified stock audit tools. Generic API presence does not establish hostile intent.

Replaced contact-email and shared editor/relay family signatures with behavior-coupled identity rules or existing native backdoor detections. Hidden request dispatch now requires adjacent import and variable-call evidence; a safe handler that overwrites imported variables no longer fires. HTTP request/body observations are notable. ASPack entry layout no longer adds a second suspicious finding to stock klogger.

Every listed member received atomscan and cleave facts inspection; all final member scans meet the required severity counts. Additional controls cover inert documentation, contact emails, request import without dispatch, fixed dynamic calls, overwritten request variables, shared shell UI fragments, and renamed variable-dispatch payloads. These controls retained zero hostile findings for benign examples and two for the dispatch payload. This is regression evidence, not a claim of universal false-positive freedom.
