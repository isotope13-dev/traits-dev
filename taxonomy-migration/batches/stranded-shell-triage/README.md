# Stranded shell-member triage

44 requested stranded members were judged from their own bytes. SHA-256
verification confirms every supplied member; the two missing master Ruby modules
were recovered from upstream with exact hash matches. The requested data.tar.gz
is the Mettle gem's inner archive, not the Debian data.tar.xz.

Laudanum and Webshells entries are command webshells, dynamic request dispatch,
reverse-shell relays, or inherited-socket shell code. Some historical templates
need compatible runtimes or configuration corrections; they remain payload source.
GoAhead ELF constructors clear LD_PRELOAD, fork, connect or accept a TCP socket,
duplicate its descriptor to standard I/O, and try POSIX shell paths. Every native
variant was decompressed and disassembled with rizin without executing it.

The Next.js module traverses cache paths to leak a server-action encryption key,
forges AES-GCM bound arguments with a Flight Function-constructor gadget, then
sends a child_process.exec payload. The SonicWall module proxies loopback OPTIONS,
stages CouchDB documents, injects native-query configuration through logging,
executes an Erlang os:cmd view, and invokes privileged XML-RPC with a sed execution
breakout. These are active exploit implementations, independently of packaging.

Mettle packages contain native Meterpreter implants: TLV command dispatch,
process execution and network handlers, together with ordinary Ruby packaging
helpers. The inspected x86_64 executable exposes and implements those handlers.
CVE-2019-13272 uses a ptrace parent-credential flaw and privileged helper processes
to overwrite tracee code/registers and obtain a root shell. The WAR XML deployment
descriptor is inert and has an independent BENIGN marker.

All 51 inspected payload artifacts (44 stranded plus listed related files)
produce 2–4 hostile traits apiece. Large outer archives aggregate descendant
findings and retain their confirmed convictions. review.json records identities,
hashes, marker paths, notes and final trait lists. Markers themselves live beside
the sample bytes, outside this repository.

The changes move vulnerability references and neutral vocabulary into their
supported homes, remove misleading capability/intent grouping, and describe
command syntax and Meterpreter references accurately. No family identity grants
a blanket behavioral exclusion. The migrations also correct complete capability
atoms already misfiled as vocabulary, without changing their scope or matchers.

Controls cover ordinary credential strings, data-field initialization, path
references, token-getter calls, regex extraction, security prose and password UI.
They require no hostile findings and at most one suspicious finding. Native bind
and reverse composites were tested against the actual binaries and have precision
scores 9.5–11.2; Next.js exploit composites score 5.9–6.0.
