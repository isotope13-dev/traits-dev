# Pinned release triage

Bytes and SHA-256 were checked for revine 1.0.1, toga-ai 1.0.979 and revine 2.4.0. Verdicts are version-specific. Archive atomscan and cleave facts were run for all three. No package code or downloaded stages were executed.

Revine 1.0.1 is a React/Vite scaffolder. Its dependency installation uses spawnSync with shell:false; interactive Git setup is ordinary scaffolding.

TOGA 1.0.979 is an enterprise Claude harness with ticket gates, skill installation, Git knowledge synchronization and defensive commit redaction. Its installer writes global ~/.claude/settings.json with OTLP HTTP content telemetry (prompts, tool details and assistant responses). TOGA_SKIP_TELEMETRY opts out. The suspicious rule describes this global configuration change, not a proved upload or credential theft.

Revine 2.4.0 contains JavaScript in public/fonts/fa-solid-500.woff2. A 125-entry rotated hex table XORed with 243 decodes module, transport and execution vocabulary. The loader resolves endpoints from Ethereum transactions, downloads stages via GET or an x-payload-b64 HEAD fallback, applies repeating-key XOR, evaluates one stage and spawns detached hidden Node children. No install-time execution path was established.

## Matcher and reference review

Shared awaited source must reach eval and child -e; both identifier equality predicates are required. Positive control renames the font to .js. Negative control changes only the child source identifier. Hostile precision scores are 7.5 and 7.8. The second hostile requires byte-encoded rotated-table concealment in addition to the linked execution stage. Neither verdict requires a package name, filename, campaign key or endpoint.

Indexed assignment now rejects === comparisons. Whole-environment JSON serialization uses the existing AST matcher, avoiding process.env.NAME false positives. Computed-call syntax duplicates are consolidated into the existing AST matcher. Credentialed-client correlation is file scoped rather than archive scoped. Generic SKILL.md basenames no longer imply OpenClaw identity; query-refetch configuration no longer implies sabotage.

Neutral observations were moved with exact references and local consumers: global module aliases, short shell identifiers, long PHP strings, variadic PHP dispatch, mklink, Git hook basenames, explicit successful Node exit, query-refetch configuration, system-reminder tags, instruction-authority and prohibited-use wording, npmrc auth vocabulary, HTTP operations, batch extension literals and defensive redaction markers. Redaction directory selectors now select only the relocated redaction directory; they do not select generic filtering. Full defaults, exclusions and size scopes were reviewed. Broad prose/source scopes narrowed where the validator's matcher-type cap required it. No extra ATT&CK or MBC intent is retained on these neutral observations.

Placement hold: execution/payload/script-eval was not admitted by this validator's sparse partition check. The response-evaluation rule remains in the admitted remote-body-exec leaf of the legacy dropper namespace. New neutral eval reuse is under process/create/eval (direct eval leaf was already at its 100-rule cap).

Mapping review: concealed stage acquisition/execution supports T1105 and T1059.007; concealed encoding supports T1027 and B0032. B0024 was removed because detached spawning does not prove a single-instance check. Neutral migrations do not inherit attacker mappings.

Evidence and scanner reports are retained under the session scratch/triage directory. The original benign archives are corpus controls.

Valid bundled WOFF2 control: cleave facts reports font.valid=true and a parsed table directory. Removed three rules that inferred parser failure or out-of-bounds tables from largest_table_bytes >=400/500/510; these thresholds prove neither claim. The unsupported out-of-bounds composite was removed, and the remaining unparsed-directory composite description now describes precisely its required facts.

The leading-whitespace-only objective duplicated a neutral padding fact; its consumers now use that canonical fact. Obfuscator-plus-padding retains its generated/minified exclusions and uses T1027/B0032 rather than unsupported packing/single-instance mappings.

Full validation exposed the existing cleartext stager regression: its awaited HTTP result is wrapped in a decode/toString call and reaches eval/code and child/code without a prefix. The structural matcher includes that form with the same source-identifier equality constraints. The PolinRider fa-solid-900 fixture minimum suspicious count changes from four to three because global module aliasing is now a neutral capability; its two-hostile requirement remains.
